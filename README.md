# Flurell.pk – CSS Assignment

## Project Overview
This project focuses on designing and styling the Flurell.pk jewelry website using CSS3. It transforms the website structure into an attractive, visually appealing, and user-friendly interface.

## Technologies Used
- CSS3
- Flexbox and CSS Grid
- CSS Variables
- Responsive Design
- Transitions and Hover Effects

## Features
- Attractive pink and lavender color theme
- Styled navigation and header
- Responsive product cards and layouts
- Custom typography and spacing
- Buttons and interactive hover effects
- Styled forms, tables, and sections
- Light and dark theme styling

## How to Use
1. Download or clone this repository.
2. Open the CSS file in a code editor.
3. Link the stylesheet to an HTML document using a `<link>` element.
4. Open the HTML document in a browser to view the styling.
